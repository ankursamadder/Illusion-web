# Wahmfashion Storefront

The customer-facing online boutique and shopping storefront for Wahm Fashion.

## Features
- **Storefront Home**: Hero banners, new arrivals, best sellers, influencer carousel.
- **Product Catalog & Details**: Browse products, categories, filters, variants, image galleries.
- **Cart & Wishlist**: Persistent cart and wishlist with Zustand state management.
- **Checkout & Orders**: Razorpay online payments and Cash on Delivery (COD) support.
- **Account & Profile**: Customer login, profile management, and order history.
- **Custom Content**: Dynamic footer pages (About Us, Contact Us, Shipping, Returns, Careers, etc.).

## Getting Started

1. Navigate to the `Wahmfashion` directory:
   ```bash
   cd Wahmfashion
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure Firebase:
   Edit `.env` with your Firebase project credentials when ready.

4. Start development server:
   ```bash
   npm run dev
   ```
   Runs by default on `http://localhost:5173`.

5. Build for production:
   ```bash
   npm run build
   ```
